# Cruz-B Enterprise Website Package

This ZIP file contains the complete source code and assets for the **Cruz-B Enterprise** website application.

## Key Features
- **Strict Theme & Palette:** Uses Warm Brown (`#5C3A21`), Soft Pink (`#E8B4B8`), and Milk Cream (`#FAF5EF`).
- **Owner POS Sync:** Includes a Super Admin POS inventory sync bridge button.
- **Multi-Currency System:** Dynamic header selector converting values in USD ($), NGN (₦), EUR (€), and GBP (£).
- **Role-Based Access Control:** Switch between Public Visitor, Secondary Admin, and Super Admin (Sole Creator).
- **Admin Management:** Hidden panel allowing the sole creator to grant/revoke secondary admin permissions.
- **Editable About & Socials Pages:** Public read-only pages with live admin editing controls.

## How to Run
1. Unzip the file.
2. Double click or open `index.html` in any modern web browser (Google Chrome, Firefox, Edge, Safari).
3. Use the simulator bar at the top of the browser window to test switching between Public, Secondary Admin, and Super Admin modes.
